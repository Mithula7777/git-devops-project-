# Git Version Control DevOps Project

## Objective
To manage a DevOps project using Git and GitHub.

## Tools Used
- Git
- GitHub
- AWS EC2 Linux

## Tasks Completed

### 1. Repository Initialization
Initialized a local Git repository.

### 2. Branch Management
Created three branches:
- main
- dev
- feature

### 3. Feature Development
Added a new feature to index.html using the feature branch.

### 4. Pull Requests
- Merged feature into dev.
- Merged dev into main.

### 5. Git Ignore
Created .gitignore to exclude unnecessary files.

### 6. Git Tag
Created version tag v1.0.

### 7. GitHub
Pushed project files and branches to GitHub.

## Outcome
Learned Git version control, branching,
commits, pushing, Pull Requests and merging.
